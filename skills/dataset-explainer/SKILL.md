---

仅当用户明确调用 `$dataset-explainer` 或明确要求使用此 skill 时使用，不自动触发。

1. 找到其 Metadata 信息。包括但不限于论文作者、学校、公司，其论文的会议或者期刊级别。其数据集网站地址在哪，相关链接。
2. 核心创新是什么，简单描述下这个数据集
3. 用个数据集中的实际数据作为例子讲解一下

用下面模板回复我：
```markdown
## metadata

## 概述

## 一条例子

```
